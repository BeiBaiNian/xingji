# 星记使用说明

适用于星记 0.5.1，Windows 构建号为 9，Android 为 16。两端都通过日历和 24 小时钟面设置提醒。Windows 可在标题或正文按 `Ctrl+V` 添加截图或浏览器图片。本机使用 SQLite，星记的本地表结构为 v3。双端同步使用 PostgreSQL，星记的服务端接口为 v2。

星记用于记录待办、到点提醒、完成归档和按日期回顾。可以单机离线使用，也可以通过自己的 PostgreSQL 同步电脑和手机。

## 安装与升级

### Windows

支持 Windows 11 x64。可直接运行 `XingJi-0.5.1-Windows-x64-Setup.exe`，也可将 `XingJi-0.5.1-Windows-x64.zip` 解压到自己的“下载”文件夹，再运行其中的同一个安装器。默认安装到 `%LOCALAPPDATA%\Programs\XingJi`，使用普通用户权限即可安装。

开发目录可能给文件附加低完整性标签，导致通知注册失败。解压到普通用户目录后安装即可，不需要修改系统安全设置。安装器会先检查通知注册权限，并将安装日志保存到用户临时目录。仍失败时可查看最新的 `Setup Log *.txt`。

升级前导出备份、退出应用，再运行新安装器。升级替换程序文件，保留资料目录。Windows 卸载也会保留资料库；通知注册、快捷方式和启动项会移除。

### Android

支持 Android 8.0 及以上。把 `XingJi-0.5.1-Android.apk` 传到手机安装，按系统提示允许文件管理器安装应用。升级时直接覆盖安装，同一签名会保留原资料。卸载会清除手机上的资料、图片及设备密钥。

打开“设置 → 系统提醒”，点击“申请通知权限”，再用“测试通知”检查能否收到通知。Android 13 及以上需要允许通知。Android 12 及以上如提示非精确提醒，点击“允许准时提醒”。需要让手机时钟在后台响铃时，按下文开启“允许后台调用时钟”。从旧版覆盖升级时，原有 SQLite 资料会迁移到 v3 并继续使用。

## 首次使用与密码

欢迎页可以创建资料库、连接已有资料库或恢复加密备份。单机使用选择创建资料库，不需要数据库账号。已有电脑资料时，手机应选择“连接已有资料库”，避免另建一个无法自动合并的空库。

主密码至少 10 个字符，负责解锁资料库，与 PostgreSQL 登录密码不同。创建后恢复码只显示一次，请离线保存。主密码、恢复码和可自动解锁的可信设备全部丢失时，数据库口令也无法恢复内容。

| 设置 | 行为 |
| --- | --- |
| Windows“记住此设备” | 用当前 Windows 账号的 DPAPI 保护密钥，下次启动可自动解锁；手动锁定或 Windows 锁屏会清除当前持有的密钥 |
| Android“三天内免输主密码” | 正确输入主密码或恢复码后固定 72 小时有效，普通打开不续期，到期后重新验证 |
| Android 关闭免密 | 下次冷启动需要密码；“立即锁定”则立即要求验证 |
| Android 手动锁定 | 暂停后台补同步，解锁后恢复；单纯 72 小时到期不暂停后台同步，也不取消已登记提醒 |

Android 从旧版本升级后的首次打开可能需要验证一次，再开始计算三天。设备保护不能替代手机锁屏和电脑账号保护。

## 记录、完成和日期查看

电脑左侧是备忘录列表；手机底部有“今天”“备忘录”“日期”三个入口。深浅色模式可随时切换并记住选择。

- **首页今天**：只显示今天未完成事项；未过时组在前、过时组在后，每组按紧急、重要、普通、较低，再按时间排序。过时变灰，不自动完成或删除。首页清单不受列表搜索筛选影响。
- **备忘录列表**：未完成按提醒时间排列，无时间项置后，已完成灰色归档在后；重要程度不打乱这里的日期顺序。支持全部、今天、以后、已完成、逾期、未设提醒、回收站和冲突副本。
- **编辑**　点“日期”在日历中翻月选日。点“时间”后，在 24 小时钟面上先点小时，再点分钟，最后点“确定”。点“取消”会保留原值。提醒按事项时区显示，时区、标签、重要程度、重复和清单可在“更多设置”中调整。输入时自动保存，点“保存并返回”回到首页，手机返回键也会保存编辑。
- **详情**：点击列表项先查看正文和属性，再选择编辑。首页与日期分组采用设备本地自然日，到期、跨天和回到前台时更新。
- **归档**：完成后取消提醒、保留内容，可按完成日期回看或重新打开。
- **重复事项**：支持每日、每周、工作日。“完成本次”保留本次归档并安排下一次；结束重复会归档当前任务，不再生成下一次。

“按日期查看”可选任意一天、前一天、后一天或回到今天。默认“当天事项”将当天提醒的未完成项和当天实际完成的归档放在一起；另可切换“安排日期”“完成日期”，并筛选全部、未完成或已完成。没有提醒时间的记录完成后也能按完成日期找到。回收站不在日期列表中；详情返回保留日期条件。

### 添加本机图片

- **Windows**　用截图工具复制截图，或在浏览器中选择“复制图片”。回到备忘录，把光标放在标题或正文，按一次 `Ctrl+V`。缩略图出现在正文下方。复制的是文字时，文字会粘贴到光标所在位置。
- **Android**　在正文下方点“选择图片”打开相册，或复制图片后点“粘贴图片”。

每条备忘录最多添加 9 张图片。点缩略图可放大查看，点缩略图上的移除按钮可删除该图。星记会校正方向、移除照片元数据，并把长边缩小到最多 2048 像素。原图上限为 32 MiB，每个资料库的图片容量上限为 500 MiB。

图片只保存在添加它的设备上。跨端同步、修改历史和导出的 `.xingji` 备份均不包含图片，换机或卸载前请另行保留原图。事项进入回收站后仍可恢复图片。移除图片或永久删除事项后，最后一条引用消失时会清除该图片的本机密文。

### 查看和恢复修改历史

停止打字、返回或切到后台会自动保存当前内容。要留一个可恢复的版本，点击“保存并返回”，相同内容只记一次。每条记录在本机最多保留 30 版，导出加密备份时会一并保存。

在详情页打开“修改历史 → 预览与恢复”，核对正文、清单和提醒信息，确认后点击“恢复此版本”。恢复前的内容会自动留在历史里，事项的完成和回收站状态保持不变。如果预览期间另一台设备改过内容，请重新打开历史核对。

## 回收站与永久删除

删除有独立按钮，经确认后进入回收站，仍可恢复。完成归档和删除是不同操作，不会自动清理旧的已完成事项。

回收站“永久删除”需再次确认，清除本机记录、历史和待发修改；联网后同步清理 PostgreSQL 和其他已升级设备的副本，不能再从回收站恢复。删除标记防止旧副本重新上传同一记录；外部备份、数据库 WAL、磁盘快照和未同步设备不会被远程擦除。

已有 v1 数据库需要管理员执行 `database/002_permanent_delete.sql`，`SELECT xingji.api_version();` 应返回 2。离线或服务端未升级时，删除请求保留待同步状态；连接恢复或升级后点击立即同步。本机已同步不代表另一台离线设备已经收到修改。

## 提醒

两端均可开关本机提醒、设置是否显示标题、发送测试通知和重新排程。默认隐藏标题。允许显示后，标题会出现在系统通知中，Android 调用时钟时也会将它传给时钟。开启夜间静默后，普通提醒在本机时间 22:00 至次日 08:00 之间顺延到 08:00。Android 上单独开启“闹铃提醒”的事项例外。

### Windows 通知、托盘与快捷键

关闭窗口会保存并退出，最小化只隐藏窗口。已登记提醒交给 Windows 管理，退出后仍可送达；睡眠、关机、免打扰和通知权限可能影响送达，程序不会唤醒关机的电脑。重新打开或从睡眠恢复后会检查逾期事项。

通知中的“完成本次”和“稍后 10 分钟”只处理对应任务的当前排程，锁定状态需要先解锁；旧通知不会误处理已修改的任务。修改、完成或删除会撤销旧排程。

最多预排最近 512 条提醒，保存、同步和睡眠恢复时更新，运行时每五分钟补查。重复任务在完成本次后计算下一次，长期退出且未处理任务时不会无限预排。随登录启动可在设置中开启。

| 快捷键 | 用途 |
| --- | --- |
| Ctrl+N | 新建 |
| Ctrl+Shift+N | 全局快速新建；被占用时使用托盘菜单 |
| Ctrl+S | 保存当前编辑并返回首页 |
| Ctrl+V | 在标题或正文粘贴图片附件或文字 |
| Ctrl+F | 搜索 |
| Ctrl+L | 锁定资料库 |

### Android 通知与后台同步

已同步到手机并登记的提醒可离线触发；手机重启后会恢复登记。电脑新建的事项须先成功同步到手机，才能由手机安排提醒。

前台自动同步，后台交给系统调度，通常约每 15 分钟获得一次机会，也可能更晚。后台补同步需要记住设备、保存连接并开启“后台补同步”。关机、强行停止、关闭通知和厂商省电策略可能影响送达；重新打开应用会检查和补排。

### Android 闹铃

在“设置 → 系统提醒”开启“本机提醒”。到点时，手机按以下设置处理已登记事项。亮屏和息屏以触发瞬间的屏幕状态为准，息屏显示按息屏处理。

| 设置 | 亮屏 | 息屏 | 开启夜间静默时 |
| --- | --- | --- | --- |
| 仅开本机提醒 | 普通通知 | 普通通知 | 顺延至 08:00 |
| 另开“息屏时系统时钟响铃” | 顶部通知和一次提示音 | 请求手机时钟启动 1 秒倒计时 | 顺延至 08:00 |
| 在单条事项上开启“闹铃提醒” | 请求手机时钟启动 1 秒倒计时 | 同亮屏 | 按事项设定时间提醒 |

要单独设置一条事项，编辑时先选提醒日期和时间，再打开“提醒时间”卡片中的“闹铃提醒”。该开关随资料库加密同步，在 Android 生效。它优先于“息屏时系统时钟响铃”开关。亮屏通知的提示音和顶部横幅可在“亮屏通知设置”中调整。

**授权与取消。** Android 10 及以上如需从后台打开时钟，点击“允许后台调用时钟”，在系统的“显示在其他应用上层”列表里允许星记。还应按提示允许准时提醒。小米、红米和澎湃系统需在系统设置里核对自启动、后台弹出界面和省电限制。若缺少授权、没有可用时钟或请求失败，星记会记录原因，并尝试发送系统允许的普通通知。

到点前改期、完成、删除或关闭本机提醒，星记会撤销相应排程。跨设备修改需先同步到手机。倒计时一旦交给手机时钟，音量、锁屏画面、响铃时长和关闭手势由时钟控制，**请在时钟中结束这一轮铃声**。事项仍保留原状态。重启后会恢复未来的排程，已错过的事项只补普通提示。

#### 在手机上验证提醒

1. **验证手机时钟能否接收请求。** 在“系统提醒”顶部选择测试场景，再点“系统时钟 10 秒测试”。若出现时钟选择或确认页，先完成确认，再回到星记、锁屏、切换应用或划走星记，按所选场景等待。此测试在点击时立即请求倒计时，可独立于下方的提醒开关使用。结束上一轮倒计时后，再开始下一轮。
2. **验证到点时如何提醒。** 开启本机提醒和“息屏时系统时钟响铃”，点“30 秒后事项测试”，再亮屏等待或锁屏。该测试经过系统排程，使用表中第二行的分流规则，不会新增备忘录。可以在倒计时交给时钟前取消测试。要检查第三行，请新建一条开启了“闹铃提醒”的真实事项。
3. **记录实际听到的声音。** 10 秒测试可填写“响铃正常 / 只有提示音 / 没有响铃 / 未完成测试”。排查时用“复制最近 10 条诊断”取得设备、版本和最近测试摘要。即使显示已向时钟发出请求，仍需在手机上确认实际是否响铃。

## PostgreSQL 双端同步

管理员先按源码或 Windows 安装目录的 `database/README.md` 初始化并配置日常账号。数据库只需部署一次，手机和电脑接入同一个资料库。

1. 两端连接同一局域网或能访问数据库的 VPN。
2. 新设备欢迎页选择“连接已有资料库”，填写主机、端口、数据库、账号和连接密码。
3. 手机主机填写电脑的局域网/VPN 地址；手机的 `127.0.0.1` 指向手机自己。
4. 测试连接后选择原资料库 ID，可在原设备设置中核对。
5. 输入原资料库主密码，等待同步。接入已有库的弹窗当前只支持主密码。

同一人可在两端使用同一数据库账号；独立账号须授权同一个资料库。不同人的资料应使用独立账号和资料库。两端分别新建的库不会自动合并，目前没有非空资料库的直接切换入口。

默认使用 TLS 校验证书与主机名，自签 CA 可选择 PEM 文件。电脑能连接而手机不能时，检查 PostgreSQL 监听地址、`pg_hba.conf` 和防火墙端口；应用不会自动修改这些设置。

本机编辑先落盘，再上传密文；断网继续使用，重连重试。两台设备同时修改时保留服务端版本和本地冲突副本，请检查合并。两端离线分别更改主密码会提示密钥包冲突，在“安全与备份”中选择保留哪一个密码，然后重新导出备份；该选择不清空任务。

## 数据位置、备份与恢复

| 平台 | 默认资料位置 | 设备保护 |
| --- | --- | --- |
| Windows | `%LOCALAPPDATA%\XingJi\vault.sqlite3` | 当前 Windows 账号 DPAPI |
| Android | `/data/user/0/app.xingji.memo/files/XingJi/vault.sqlite3` | Android Keystore |

实际路径可在应用设置查看。标题、正文、标签等业务字段认证加密，PostgreSQL 保存业务密文；SQLite 整文件并非加密，ID、游标、提醒时间等运行元数据仍可见。

在“安全与备份”导出 `.xingji` 加密备份，包含记录、回收站和本机历史，不包含连接密码或设备可信凭据。可在新设备的欢迎页恢复，需要备份时的主密码或恢复码，本机须没有现有资料库。恢复后重新配置同步；不要直接把 Windows 设备凭据复制到 Android。Android 系统自动备份已关闭，迁移使用星记导出文件。

Android 恢复备份时会在应用私有缓存中创建工作副本。恢复成功、取消或失败后都会清理该副本。如果应用中途被系统终止，下次打开会清理遗留副本。文件选择器中选中的原始备份仍在原处。

更改主密码后重新导出备份。更改密码只重新包装同一数据密钥，旧备份仍能用旧密码或对应恢复码打开，不会撤销已经复制的内容和密钥。

## 当前范围

Windows 与 Android 均支持本机图片。完整月历、自动更新、完整数据密钥轮换与跨设备本机历史同步暂未提供。Windows 安装器未配置商业代码签名。提醒受系统权限和后台策略约束，Android 新系统、厂商机型和长期大量数据仍需进一步实测。
